# Stepwise downloads

Installers for **Stepwise**, the desktop app for IBM Sterling OMS by [Second Act Labs](https://stepwise.secondactlabs.io).
Run any IBM Sterling OMS API, service or agent against your real environment, in a sandbox that never writes back.

**Get Stepwise:** [stepwise.secondactlabs.io](https://stepwise.secondactlabs.io/#download), or pick a build from the [latest release](https://github.com/Second-Act-Labs/stepwise-downloads/releases/latest).

| Platform | File |
|---|---|
| macOS, Apple Silicon | `Stepwise-<version>-arm64-mac.zip` or `.dmg` |
| macOS, Intel | `Stepwise-<version>-mac.zip` or `.dmg` |
| Windows x64 | `Stepwise-<version>-setup.exe` (installer) or `-portable.exe` |

Each release also carries the Stepwise JDBC driver (`stepwise-jdbc.jar`) and the MCP connector (`stepwise-mcp.jar`).
Installed copies update themselves from `latest.json`.
